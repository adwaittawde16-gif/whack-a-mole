# 🐭 Whack-a-Mole

A classic Whack-a-Mole arcade game built with JavaScript.

## 🎮 Features

- Randomized mole appearances
- Score counter with a timer
- Increasing difficulty as the game progresses

## 🛠️ Tech Stack
- HTML / CSS / JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/adwaittawde16-gif/whack-a-mole.git
cd whack-a-mole
# Open index.html in your browser
```
